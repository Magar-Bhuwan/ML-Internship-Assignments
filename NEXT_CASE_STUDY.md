# Next Case Study Plan

## Where the next case study will go

The next case study will be added to the **Projects / Case Studies section of my portfolio**. It will follow the same structure as my existing portfolio case studies and will include a link to the related project repository or deployed application when available.

## How I will add the next case study

I will use the Week 2 three-beat structure:

### 1. Problem

Explain the real problem the project was designed to address.

I will describe:

* What problem or need I identified
* Who the problem matters to
* Why solving it is useful

### 2. What I Did

Explain how I worked on the problem.

I will include:

* The data or inputs used
* Data cleaning and preparation
* Analysis or machine-learning methods
* Important tools and technologies
* Key decisions made during the project

### 3. What Came of It

Explain the result and its practical meaning.

I will include:

* The main findings or results
* Important metrics or evidence
* What the result means for a user or decision-maker
* Limitations and possible next improvements

## Publishing steps

1. Complete the project and confirm the final results.
2. Write the case study using **Problem → What I Did → What Came of It**.
3. Add the case study to the Projects / Case Studies section of my portfolio.
4. Add relevant screenshots, charts, or other evidence.
5. Link the project repository or deployed application when appropriate.
6. Check the updated case study on desktop and mobile.
7. Publish the portfolio update.
8. Verify that the project is visible from the portfolio Projects section.
